# Contributing to cli-starter

Thanks for your interest in cli-starter!

## Current status: not accepting external contributions

The cli-starter is in early development and is currently maintained as a personal project. At this stage, **we are not accepting external pull requests**. Please do not open PRs — they will be closed without review.

This isn't a reflection on the quality of any contribution; the project's direction, scope, and internal conventions are still in flux, and accepting outside code would make that harder to iterate on.

## What you _can_ do

- **Report bugs** — open a [GitHub Issue](https://github.com/coryrylan/cli-starter/issues) with:
  - CLI version (`mycli --version`, or `bun projects/cli/src/index.ts --version` from the repo root) and platform (OS, architecture)
  - The command you ran and the output you got, with sensitive data removed
  - What you expected instead
- **Suggest features** — issues are welcome. A clear use case is more useful than a proposed implementation.
- **Ask questions** — open a [GitHub Discussion](https://github.com/coryrylan/cli-starter/discussions) if you're unsure whether something is a bug, a feature request, or intended behavior.
- **Report security issues privately** — see [SECURITY.md](SECURITY.md). Do not open public issues for vulnerabilities.

## When this will change

If the project begins accepting external pull requests, this file will be updated with contribution guidelines and a PR workflow. Until then, please use issues for bug reports and feature requests.
